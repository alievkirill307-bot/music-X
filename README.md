# MusicX

**Локальный музыкальный веб-сервис с тремя источниками**

Бесплатный поиск, прослушивание и скачивание музыки — без установки приложений и аккаунтов. Всё работает локально на твоём компьютере.

## 🚀 Как запустить

### Требования
- **Node.js 18+** — [скачать](https://nodejs.org/)

### Установка и запуск

```bash
# 1. Склонировать или скачать проект
git clone <url-проекта>
cd z.net

# 2. Установить зависимости
npm install

# 3. Запустить
npm start
```

После запуска браузер **откроется автоматически** на [http://localhost:3000](http://localhost:3000).

Или запусти через файл **`start_server.bat`** — браузер откроется сам.

### 📦 Портативная версия
В папке `MusicX_Distrib/` лежит готовый переносной дистрибутив:
- Распакуй в любую папку
- Запусти `start.bat`
- При первом запуске создастся ярлык `MusicX` на рабочем столе

Никаких установок — Node.js уже в комплекте.

## 🏗️ Как это работает

```
┌─────────────────────────────────────────────┐
│                 БРАУЗЕР                      │
│       SPA (public/): поиск, плеер, UI       │
└──────────────────────┬──────────────────────┘
                       │  HTTP / JSON (localhost:3000)
┌──────────────────────▼──────────────────────┐
│              NODE.JS + EXPRESS               │
│                   (server.js)                │
│  ┌────────────┬─────────────┬────────────┐   │
│  │  Zaycev    │   Hitmo     │  Muzofond  │   │
│  │  JSON API  │  HTML parse │  HTML parse│   │
│  └────────────┴─────────────┴────────────┘   │
│        агрегация + дедупликация              │
│  ┌──────────────────────────────────────┐    │
│  │  SQLite (sql.js WASM): избранное,    │    │
│  │  плейлисты, история, рекомендации     │    │
│  └──────────────────────────────────────┘    │
│  ┌──────────────────────────────────────┐    │
│  │  Кэш MP3 (cache/music/)               │    │
│  └──────────────────────────────────────┘    │
└──────────────────────────────────────────────┘
```

**Три источника → один результат:**
1. Запросы к трём источникам выполняются **параллельно**
2. Треки объединяются и **дедуплицируются** (по паре «исполнитель + название»)
3. В ответе — единый список с метаданными: обложка, длительность, ссылка на поток

**Воспроизведение:**
- **Zaycev** — поток через официальное API (`/track/play/{hash}`)
- **Hitmo / Muzofond** — прямые MP3, проксируются через сервер для обхода CORS

**Рекомендации «Для тебя»** — взвешенная система по вашему вкусу:

| Источник | Вес |
|---|---|
| Избранные артисты | ×20 |
| Избранные треки | ×10 за трек |
| Плейлисты | ×5 за трек |
| Прослушивания | 1–5 (зависит от свежести) |

## ⚙️ Конфигурация (`config.json`)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `port` | `3000` | Порт сервера |
| `cacheDir` | `./cache/music` | Папка для скачанных MP3 |
| `logsEnabled` | `false` | Писать логи в файл |
| `autoCache` | `false` | Автокэширование прослушанного |
| `language` | `ru` | Язык интерфейса по умолчанию |
| `maxSearchResults` | `35` | Лимит результатов поиска |
| `maxRecommendedTracks` | `150` | Лимит рекомендаций |
| `proxyTimeout` | `120000` | Таймаут проксирования MP3 (мс) |
| `requestTimeout` | `15000` | Таймаут запросов к источникам (мс) |
| `sources` | все `true` | Включение/отключение источников |

## 📡 API

### Поиск и контент
| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/api/search?q=` | Объединённый поиск (треки + артисты) |
| GET | `/api/search-suggest?q=` | Автоподсказки при вводе |
| GET | `/api/new?page=` | Новинки с пагинацией |
| GET | `/api/genres` | Список жанров |
| GET | `/api/genre-tracks?genre=&page=` | Треки жанра |
| GET | `/api/sections` | Карусели главной страницы |
| GET | `/api/recommended` | Персональные рекомендации |
| GET | `/api/artist?id=&page=` | Артист (Zaycev) |
| GET | `/api/hitmo-artist?id=` | Артист (Hitmo) |
| GET | `/api/muzofond-artist?name=` | Артист (Muzofond) |

### Воспроизведение и кэш
| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/api/stream-url?hash=` | URL потока (Zaycev) |
| GET | `/api/proxy?url=` | Прокси MP3 (обход CORS) |
| GET | `/api/download?url=&title=&artist=&source=` | Скачать в кэш |
| GET | `/api/cache-list` | Список скачанного |
| DELETE | `/api/cache-delete?file=` | Удалить из кэша |
| POST | `/api/auto-cache-toggle` | Автокэш вкл/выкл |

### Данные пользователя
| Метод | Эндпоинт | Описание |
|---|---|---|
| GET/POST/DELETE | `/api/favorites` | Избранные треки |
| GET/POST/DELETE | `/api/favorite-artists` | Избранные артисты |
| GET/POST/DELETE | `/api/playlists` | Плейлисты |
| GET/POST/DELETE | `/api/playlists/:id` | Треки плейлиста |
| POST | `/api/history/listen` | Запись прослушивания |
| GET | `/api/history/taste` | Анализ вкуса |
| GET/POST | `/api/settings` | Настройки |

## 🛠️ Частые вопросы

**Музыка не воспроизводится?**
Проверь интернет-соединение. Некоторые источники могут временно ограничивать запросы — подожди пару минут и попробуй снова.

**Где хранятся скачанные треки?**
В папке `cache/music/` рядом с проектом.

**Можно ли сменить порт?**
Да, измени `port` в `config.json`.

**Что если источник недоступен?**
MusicX работает с тремя источниками — если один упал, другие продолжат работать. Можно отключить проблемный в `config.json` → `sources`.
