1. ОБЗОР
=========================================================================
=======
MusicX — это локальный музыкальный сервис, работающий на вашем
компьютере.
Весь функционал доступен через обычный браузер по адресу localhost.
Преимущества:
- Никакой регистрации и аккаунтов
- Никакой рекламы
- Никаких подписок
- Полная приватность — данные хранятся только на вашем ПК
- Работает полностью оффлайн после кэширования треков
=========================================================================
=======
2. КАТАЛОГ ТРЕКОВ
=========================================================================
=======
MusicX объединяет крупнейшие музыкальные библиотеки в едином каталоге.
> 5 000 000 треков на любой вкус
- Русская музыка: от классики до современного рэпа
- Зарубежная музыка: поп, рок, электроника, хип-хоп
- Клипы и альбомы всех направлений
- Новинки и хиты, обновляемые ежедневно
За один запрос поиска отдаётся до 105 треков (по 35 с каждого
источника),
что позволяет мгновенно находить нужную музыку.
Интеллектуальная дедупликация убирает повторы — вы видите только
уникальные
треки, даже если они есть в нескольких каталогах одновременно.

3. ПОИСК
=========================================================================
=======
Мощная система поиска с мгновенными результатами.
Виды поиска:
- По названию трека: "Белые розы"
- По имени артиста: "Кино"
- Комбинированный: "Eminem Lose Yourself"
- По частичному совпадению: "Король и Шут"
Дополнительно:
- Выпадающие подсказки при вводе (автокомплит)
- Голосовой поиск (работует в Chrome и Edge)
- Результаты сгруппированы: сначала артисты, затем треки
- Цветовое выделение текущего трека в результатах

4. ЖАНРЫ
=========================================================================
=======
Более 20 жанров с наглядными обложками.
Поп, Рок, Рэп, Электроника, Шансон, Метал, Классика,
Танцевальная, Лёгкая, R'n'B, Джаз, Регги, Блюз,
Фолк, Инди, Инструментальная, Мировая, Детская,
Саундтреки, Другое
Каждый жанр открывает подборку популярных треков.
Нажатие на жанр мгновенно загружает актуальные хиты.

5. АРТИСТЫ
=========================================================================
=======
Полноценные страницы артистов с дискографией.
- Список всех треков артиста
- Обложки и информация
- Переход из результатов поиска
- Сохранение артистов в избранное
- Быстрый доступ к дискографии из избранных артистов
Кнопка "Избранные артисты" в боковом меню показывает
сохранённых исполнителей с возможностью:
- Прослушать все треки артиста
- Прослушать ВСЕХ избранных артистов (Play All)
- Убрать из избранного в один клик
=========================================================================

6. ИЗБРАННОЕ
=========================================================================
=======
Система избранного для быстрого доступа к любимой музыке.
Избранные треки:
- Добавление/удаление в один клик (сердечко на треке)
- Сохраняется полная информация о треке
- Быстрый доступ через меню "Избранное"
- Кнопка "Воспроизвести все" для полного списка
Избранные артисты:
- Сохранение артистов с обложками
- Отдельный раздел в боковом меню
- Каждый артист открывает полную дискографию
- Кнопка "Play All" для воспроизведения всех артистов
Данные хранятся в локальной базе SQLite.

7. ПЛЕЙЛИСТЫ
=========================================================================
=======
Создавайте собственные подборки треков.
Функции:
- Создание неограниченного количества плейлистов
- Добавление треков из любого места (поиск, артист, избранное)
- Удаление треков из плейлиста
- Переименование и удаление плейлистов
- Воспроизведение всех треков плейлиста
- Порядок треков: как добавлены
Управление:
- Меню плейлистов в боковой панели
- Кнопка "+" для создания нового
- Иконка корзины для удаления
- Трёхточечное меню для действий

8. РЕКОМЕНДАЦИИ
=========================================================================
=======
Персональные рекомендации на основе ваших вкусов.
Как работает:
1. Система анализирует ваши прослушивания
2. Учитывает избранные треки и плейлисты
3. Учитывает избранных артистов
4. Весовая система оценки:
- Избранные артисты: x20
- Избранные треки: x10
- Плейлисты: x5
- Прослушивания: x1 (с учётом давности)
5. Формирует до 150 персональных треков
Чем больше вы слушаете — тем точнее рекомендации.
Рекомендации обновляются при каждом открытии раздела.
=========================================================================

9. ПРОИГРЫВАТЕЛЬ
=========================================================================
=======
Полноценный встроенный проигрыватель.
Управление:
- Воспроизведение / Пауза
- Следующий / Предыдущий трек
- Перемотка (клик по прогресс-бару)
- Громкость (слайдер + колёсико мыши)
- Режим повтора всего списка
- Повтор одного трека (кнопка Repeat)
- Перемешивание (Shuffle)
Прогресс-бар:
- Плавная анимация 60 FPS
- Отображение текущего и общего времени
- Клик для перемотки
Автоматика:
- Автопереход к следующему треку
- Сохранение последнего трека (продолжает при перезагрузке)
- Сохранение громкости

10. ОФФЛАЙН-РЕЖИМ И КЭШИРОВАНИЕ
=========================================================================
=======
Работа без подключения к интернету.
Автоматический оффлайн:
- При потере интернета автоматическое переключение
- Пропуск треков без локального кэша
- Плавное воспроизведение без вылетов
Кэширование треков:
- Скачивание MP3 в локальную папку ./cache/music/
- Структура папок: cache/music/артист/трек.mp3
- При повторном прослушивании используется локальная копия
- Управление кэшем: просмотр и удаление скачанных файлов

11. НАСТРОЙКИ
=========================================================================
=======
Гибкая настройка под себя через встроенный интерфейс.
Основные настройки:
- Порт сервера (по умолчанию 3000)
- Тема оформления: тёмная / светлая
- Язык интерфейса: Русский / English
Источники:
- Включение/выключение каждого источника по отдельности
- Три источника музыки, объединённые в один каталог
Производительность:
- Лимит результатов поиска (от 10 до 50 треков)
- Лимит рекомендаций (от 50 до 300 треков)
- Таймаут запросов (от 5 до 30 секунд)
- Таймаут прокси (от 30 до 300 секунд)
Система:
- Логирование: включение/выключение записи логов
- Автокэширование: автоматическое скачивание при прослушивании
- Конфигурация хранится в config.json

12. ИНТЕРФЕЙС
=========================================================================
=======
Современный минималистичный дизайн.
Визуальные элементы:
- Тёмная тема (по умолчанию)
- Светлая тема
- Плавные анимации и переходы
- Градиентные фоны
Режимы отображения:
- Список: компактный вид, удобен для большого количества треков
- Плитки: крупные обложки, наглядный вид
Боковое меню:
- Поиск / Главная
- Новое
- Жанры
- Рекомендации
- Избранное
- Плейлисты
- Избранные артисты
- Настройки
Верхняя панель:
- Кнопка "Назад" (при просмотре артиста)
- Строка поиска с подсказками
- Кнопка голосового ввода
- Громкость
- Переключатель темы
- Язык интерфейса
Адаптивность:
- Работает на любом разрешении экрана
- Корректное отображение на маленьких мониторах

13. ПОРТАТИВНАЯ ВЕРСИЯ
=========================================================================
=======
Автономная версия для запуска на любом компьютере.
Что включено:
- MusicX (сервер и интерфейс)
- Node.js (встроенный, не требует установки)
- Конфигурация по умолчанию
Как использовать:
1. Скопируйте папку MusicX_Distrib на компьютер
2. Установите зависимости: npm install (если node_modules отсутствуют)
3. Запустите start.bat
4. Откройте браузер: http://localhost:3000
5. При первом запуске создаётся ярлык на рабочем столе
Отправка другу:
- Скопируйте всю папку MusicX_Distrib
- Передайте любым удобным способом (USB, сеть, облако)
- Другу не нужно ничего устанавливать

14. ГОЛОСОВОЙ ПОИСК И ПОДСКАЗКИ
=========================================================================
=======
Удобные инструменты для быстрого поиска.
Голосовой поиск:
- Нажмите кнопку микрофона в строке поиска
- Говорите — текст появляется в строке поиска в реальном времени
- Нажмите кнопку ещё раз для остановки
- Нажмите Enter для поиска
- Работает в Chrome и Edge (требуется микрофон)
Подсказки при поиске:
- При вводе от 2 символов появляются подсказки
- Результаты обновляются с задержкой 300 мс
- Подсказки показывают артистов и треки
- Клик по подсказке заполняет строку и ищет
- Закрытие по Escape или клику снаружи
